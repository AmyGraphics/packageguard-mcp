# 🛡️ PackageGuard MCP

Live npm and PyPI package vulnerability and supply-chain risk intelligence.

ChatGPT can explain security concepts. PackageGuard queries the live package registry and OSV.dev so developers and AI agents can check what is true for a package and version right now.

## Tools

- `package.architect` — security review plan
- `package.profile_live` — live version, maintenance and metadata
- `vulnerabilities.scan_live` — live OSV advisories and CVEs
- `dependencies.audit_live` — known vulnerability exposure
- `license.review` — commercial license review checklist
- `package.score_live` — transparent package risk score
